# abdeen-labs/tap

Homebrew casks for apps by abdeen-labs.

| App | Install |
| --- | --- |
| [Espalier](https://espalier.abdeen.dev), a native Git client for the Mac | `brew install --cask abdeen-labs/tap/espalier` |
| [Frost](https://abdeen.dev/frost), a menu bar app that freezes your keyboard, mouse, and trackpad while your screen stays visible | `brew install --cask abdeen-labs/tap/frost` |

Installing by the full name, as above, needs no `brew tap` or `brew trust`
first. The apps update themselves, so `brew upgrade` leaves them alone unless
it's run with `--greedy`.
